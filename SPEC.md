Build a Python 3.11+ package `print_preflight` (Pillow only) with a library API and a CLI. Input: a local raster path (PNG/JPEG/TIFF) and a target profile JSON `{print_width_in, print_height_in, dpi_target, dpi_warn, bleed_in, safe_margin_in, aspect_tolerance, edge_coverage_min}`. Output: a report dict/JSON `{status: 'pass'|'warn'|'fail', effective_dpi, aspect_delta, coverage_ratio, centering_delta_px, edge_coverage, reasons: [codes]}` where every reason code is documented in README. Checks: pixel dimensions vs. required at dpi_target (fail) and dpi_warn (warn); aspect ratio vs. target within tolerance; bleed/safe-margin coverage computed from the non-transparent / non-background bounding box; edge coverage (fraction of each edge band that is non-background) for art that must bleed; centering of the content box. Deterministic, no network, no model calls, no uploads, no writes except the optional `--out` JSON. CLI: `print-preflight check IMAGE --profile P.json [--json|--text]`, exit 0 pass, 1 warn, 2 fail, 3 error. Tests: pytest; procedurally generated fixtures (solid, checkerboard, bordered, transparent-margin, off-centre) created by a committed script; property tests on rounding boundaries (hypothesis) for DPI and aspect; golden JSON reports.
